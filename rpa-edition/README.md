# 旅游运营助手 RPA 版

独立的 Electron 程序，和仓库根目录的接口版互不依赖。所有群消息都通过本机（或局域网执行端）已登录的企业微信 / 微信桌面客户端发出，**不调用任何企业微信官方接口**（没有 `@wecom/cli`，不请求 qyapi.weixin.qq.com），不需要企业微信管理后台权限。适合账号挂在别的企业下（例如携程）、进不了管理后台的情况。

## 构建和运行

需要 Windows x64 和 Node.js 18+，在本目录下执行：

```powershell
cd rpa-edition
npm install
npm run typecheck
npm run dev      # 开发运行
npm run build    # 生成 dist\TravelBot-RPA-Setup-<版本>.exe
```

安装后的程序名为 TravelBotRPA，数据保存在自己的用户数据目录，和接口版分开。

## 业务模块

和接口版一样的 7 个模块，外加两种自动任务来源：

- 首页、素材库、路线管理、内容中心（模板生成文案，人工编辑和审核）、运行日志。
- 运营任务：选审核通过的内容、发送群和时间，可附天气，内容关联路线时自动带上路线素材里的攻略图；支持“预演”（检查账号、客户端和防封规则，不发送）。
- 行程提醒（运营任务 → 旅游团行程提醒）：从 Excel 粘贴行程（群名、日期、时间、地点、事项、城市、单独发送）。出行前一天晚上发“明日行程 + 天气”，勾选“单独发送”的节点开始前再提醒一次。群名对应群管理里的群。默认干跑模式，只生成内容不发送。
- 每日推送（运营任务 → 每日推送）：每天定时发“天气 + 今日推荐”到选中的群，失败的群 10 分钟后重试，每天最多 3 次。
- 群管理：按群名添加群（可从 Excel 整列粘贴），绑定发送账号，启用停用，测试发送。
- 设置：RPA 客户端、防封规则、账号池。

## 怎么发出去

程序自动操作已登录的客户端：切到前台 → 搜索快捷键（默认 Ctrl+F）→ 粘贴群名 → ↓ 选中第一个结果 → 回车进群 → 核对群名 → 粘贴文字 → 逐张粘贴图片 → 发送键。

- 每次按键前都会确认前台仍是客户端窗口，被切走就停止；多个任务同时到点会排队执行；结束后恢复剪贴板。
- 发送前核对群名（默认开）：进群后用 Windows 自带 OCR 识别聊天窗口标题，和群名对不上就不发，记为失败。如果群名还留在搜索框里，说明没进到群，也会停止、不粘贴。需要系统装有中文“光学字符识别”语言功能（“检测本机客户端”会提示）；识别截图保存在数据目录的 `rpa\chat-title.png`。
- 发送成功后把客户端最小化，切回发送前的窗口（默认开，可在设置里关）。弹出安全验证时不收起，方便扫码。
- 可选“只粘贴，人工按发送”，用于试跑。
- 限制：电脑不能锁屏，发送时会占用屏幕和剪贴板几秒钟。

## 防封

- 每步操作随机停顿；群与群之间随机间隔（默认 60–180 秒）；图片之间随机 2.5–6 秒。
- 每小时 / 每天 / 单群每天限次（默认 10 / 40 / 3）。
- 只在发送时段内发（默认 07:30–21:30），时段外到点的运营任务自动顺延。行程提醒和每日推送的时间要设在时段内。
- 连续失败 3 次暂停 30 分钟。
- 开头随机加一句问候（默认开），避免多个群收到的文字完全一样。
- 安全验证检测：发送前和发完后用 OCR 检查客户端有没有弹出“安全验证 / 设备环境异常”。弹出就暂停这个账号的全部发送，并弹系统通知（验证有时限，超时会被退出登录）。发完才弹出的，这条算已发送、不重发。扫码验证后到“设置”点“检测本机客户端”，没有弹窗就恢复发送。
- 提醒邮件：在“设置 → 提醒邮件”填 SMTP（腾讯企业邮 smtp.exmail.qq.com:465、QQ 邮箱 smtp.qq.com:465 等）、发件邮箱、授权码和收件人，弹出安全验证时会发邮件。授权码用 Windows DPAPI 加密保存；可以先点“发测试邮件”。每台电脑（主控、执行端）各自配置。
- 风控无法完全避免：模拟按键能被客户端识别。建议用一台专用的实体电脑长期登录（虚拟机可能被判为环境异常），发送时不开远程控制、录屏、抓包工具，也不要有人操作这台电脑；新账号前一两周少发。

## 账号池（多台电脑）

企业微信一个账号只能稳定登录一台电脑，多个账号就用多台电脑、一台一个账号。

- 一台设为“主控”，管素材、内容、任务和群。其他电脑装好本程序，在“设置 → 本机角色”选“执行端”，把显示的 IP、端口（默认 47820）和配对口令填到主控的“账号池”里。
- 群管理里给每个群选“发送账号”，没选的用第一个可用账号。主控把发送指令和图片通过局域网交给对应执行端，执行端用本机客户端发。
- 防封限频、群间隔和熔断由每台执行端按自己的账号计算；发送时段以主控为准。
- 主控和执行端需在同一局域网，第一次启动执行端时 Windows 防火墙会询问，选“允许”。
